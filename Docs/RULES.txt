# RULES.txt — LegacyLens Development Guidelines for Cursor AI

## 🎯 PROJECT OVERVIEW

**Product Name:** LegacyLens  
**Tagline:** "Onboard to any codebase in hours, not weeks"  
**Type:** AI-powered legacy code intelligence platform

**Core Value Proposition:**
Help developers understand inherited/legacy codebases 10x faster using:
- AI-powered semantic code search and Q&A
- Automatic architecture visualization
- Meeting → code linking
- Trello-style onboarding task board

**Target Users:**
1. Software consultancies & dev agencies (primary)
2. New hires at tech companies (secondary)
3. Engineering managers (tertiary)

---

## 📐 ARCHITECTURE PRINCIPLES

### **1. Start Simple, Scale Intentionally**
- MVP: Monolithic API server + separate background workers
- Use message queues (BullMQ) for heavy tasks (indexing, transcription)
- Avoid premature microservices — extract only when needed

### **2. Cost-First Mentality**
- Use cheapest reliable AI APIs:
  - Groq (LLM + transcription) — 10x cheaper than OpenAI
  - Cohere (embeddings + reranking) — cheapest embeddings
- Aggressive caching (Redis, 1hr TTL for Q&A)
- Backblaze B2 for storage (10x cheaper than S3)
- Supabase for PostgreSQL + Auth (generous free tier)

### **3. Type Safety Everywhere**
- Full TypeScript (no `any` types allowed)
- Zod for runtime validation
- Prisma for type-safe database queries
- tRPC for type-safe API (shared types between frontend/backend)

### **4. Developer Experience First**
- Fast local dev setup (<5 minutes)
- Hot reload for frontend + backend
- Docker Compose for local dependencies (Redis, Postgres)
- Clear error messages (no cryptic stack traces)

## 🔧 CODING STANDARDS

### **TypeScript**

**✅ ALWAYS:**
```typescript
// Use strict types
interface User {
  id: string;
  email: string;
  credits: number;
}

// Explicit return types on functions
async function getUser(id: string): Promise<User | null> {
  return await prisma.user.findUnique({ where: { id } });
}

// Use Zod for runtime validation
const CreateProjectSchema = z.object({
  name: z.string().min(1).max(100),
  githubUrl: z.string().url().optional(),
});

// Proper error handling
try {
  await indexProject(projectId);
} catch (error) {
  logger.error({ error, projectId }, 'Indexing failed');
  throw new TRPCError({
    code: 'INTERNAL_SERVER_ERROR',
    message: 'Failed to index project',
  });
}
```

**❌ NEVER:**
```typescript
// No 'any' types
let data: any = await fetchData(); // ❌

// No non-null assertions unless absolutely certain
const user = await getUser(id)!; // ❌

// No unhandled promises
fetchData(); // ❌ (no await or .catch())

// No console.log in production code
console.log('User created'); // ❌ (use logger)
```

### **Backend (tRPC)**

**✅ ALWAYS:**
```typescript
// Protect routes that need authentication
export const projectRouter = router({
  create: protectedProcedure // ✅ Requires auth
    .input(CreateProjectSchema)
    .mutation(async ({ input, ctx }) => {
      // ctx.user is guaranteed to exist
      const project = await ctx.prisma.project.create({
        data: {
          name: input.name,
          members: {
            create: {
              userId: ctx.user.id,
              role: 'owner',
            },
          },
        },
      });
      
      return project;
    }),
});

// Use transactions for multi-step operations
await prisma.$transaction(async (tx) => {
  await tx.user.update({ where: { id }, data: { credits: { decrement: 100 } } });
  await tx.usageLog.create({ data: { userId: id, action: 'index', costCredits: 100 } });
});

// Validate all inputs with Zod
.input(z.object({
  projectId: z.string().uuid(),
  question: z.string().min(1).max(500),
}))
```

**❌ NEVER:**
```typescript
// No unprotected mutations
export const projectRouter = router({
  delete: publicProcedure // ❌ Should be protectedProcedure
    .mutation(async ({ input }) => {
      await prisma.project.delete({ where: { id: input.id } });
    }),
});

// No raw SQL (use Prisma unless absolutely necessary)
await prisma.$queryRaw`DELETE FROM projects WHERE id = ${id}`; // ❌

// No missing error handling
const project = await prisma.project.findUnique({ where: { id } });
return project.name; // ❌ (what if project is null?)
```

### **Worker Jobs (BullMQ)**

**✅ ALWAYS:**
```typescript
// Update progress for long-running jobs
await job.updateProgress(50); // Show user progress

// Handle failures gracefully
const worker = new Worker('indexing', async (job) => {
  try {
    await indexProject(job.data.projectId);
  } catch (error) {
    logger.error({ error, jobId: job.id }, 'Job failed');
    
    await prisma.project.update({
      where: { id: job.data.projectId },
      data: { status: 'failed', indexingError: error.message },
    });
    
    throw error; // Let BullMQ handle retries
  }
}, {
  connection: redisConnection,
  concurrency: 2,
  limiter: {
    max: 10,
    duration: 60000, // Max 10 jobs per minute
  },
});

// Always clean up temp files
try {
  await processFiles(tempDir);
} finally {
  await fs.rm(tempDir, { recursive: true });
}
```

**❌ NEVER:**
```typescript
// No infinite loops or blocking
while (true) { // ❌
  await checkStatus();
}

// No missing cleanup
await cloneRepo(tempDir);
await processRepo(tempDir);
// ❌ Forgot to delete tempDir

// No silent failures
try {
  await processJob();
} catch (error) {
  // ❌ Swallowed error, job marked as success
}
```

## 🔐 SECURITY RULES

### **Authentication**

**✅ ALWAYS:**
```typescript
// Validate JWT on every protected route
export const protectedProcedure = t.procedure.use(async ({ ctx, next }) => {
  if (!ctx.user) {
    throw new TRPCError({ code: 'UNAUTHORIZED' });
  }
  return next({ ctx: { user: ctx.user } });
});

// Verify project access before mutations
const project = await prisma.project.findFirst({
  where: {
    id: input.projectId,
    members: {
      some: { userId: ctx.user.id },
    },
  },
});

if (!project) {
  throw new TRPCError({ code: 'NOT_FOUND' });
}
```

**❌ NEVER:**
```typescript
// No trusting client-provided user IDs
const userId = input.userId; // ❌ Use ctx.user.id instead

// No exposing sensitive data
return {
  user: {
    id: user.id,
    email: user.email,
    githubToken: user.githubToken, // ❌ Never send tokens to client
  },
};
```

## 💰 COST OPTIMIZATION RULES

### **AI API Usage**

**✅ ALWAYS:**
```typescript
// Cache Q&A responses
async function getAnswer(question: string, projectId: string) {
  const cacheKey = `qa:${projectId}:${hash(question)}`;
  
  // Check cache first
  const cached = await redis.get(cacheKey);
  if (cached) return JSON.parse(cached);
  
  // Generate answer
  const answer = await generateAnswer(question, projectId);
  
  // Cache for 1 hour
  await redis.set(cacheKey, JSON.stringify(answer), 'EX', 3600);
  
  return answer;
}

// Batch embedding requests
const BATCH_SIZE = 96; // Cohere max
for (let i = 0; i < texts.length; i += BATCH_SIZE) {
  const batch = texts.slice(i, i + BATCH_SIZE);
  const embeddings = await cohere.embed({ texts: batch });
  // ...
}

// Truncate context to save tokens
const context = relevantFiles.slice(0, 5).map(f => 
  f.content.slice(0, 1000) // Max 1K chars per file
).join('\n\n');
```

**❌ NEVER:**
```typescript
// No embedding every single file individually
for (const file of files) {
  const embedding = await cohere.embed({ texts: [file.content] }); // ❌ Slow + expensive
}

// Batch instead:
const embeddings = await cohere.embed({ texts: files.map(f => f.content) }); // ✅

// No sending entire files to LLM
const answer = await groq.chat({ messages: [{ role: 'user', content: fileContent }] }); // ❌
```

## 🎓 COMMON MISTAKES TO AVOID

### **1. Not Using Transactions**
❌ **Wrong:**
```typescript
await prisma.user.update({ where: { id }, data: { credits: 100 } });
await prisma.usageLog.create({ data: { userId: id, action: 'purchase' } });
```

✅ **Correct:**
```typescript
await prisma.$transaction([
  prisma.user.update({ where: { id }, data: { credits: 100 } }),
  prisma.usageLog.create({ data: { userId: id, action: 'purchase' } }),
]);
```

---

### **2. Not Validating User Access**
❌ **Wrong:**
```typescript
await prisma.project.delete({ where: { id: input.projectId } });
```

✅ **Correct:**
```typescript
const project = await prisma.project.findFirst({
  where: {
    id: input.projectId,
    members: { some: { userId: ctx.user.id, role: 'owner' } },
  },
});

if (!project) throw new TRPCError({ code: 'FORBIDDEN' });

await prisma.project.delete({ where: { id: input.projectId } });
```

---

### **3. Not Handling Async Errors**
❌ **Wrong:**
```typescript
async function processJob(job) {
  const data = await fetchData(); // Might throw
  updateDatabase(data); // Might fail
}
```

✅ **Correct:**
```typescript
async function processJob(job) {
  try {
    const data = await fetchData();
    await updateDatabase(data);
  } catch (error) {
    logger.error({ error, jobId: job.id }, 'Job failed');
    Sentry.captureException(error);
    throw error;
  }
}
```
